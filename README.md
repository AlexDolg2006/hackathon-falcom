# Питомец Финни — hackathon-falcon (ДОПИСАААААТЬ!!!!)

Игровой сервис для формирования базовых финансовых навыков у детей 7–11 лет.

## Стек
- Java
- Android (нативная разработка)
- Room / SQLite для локального хранения

## Быстрый запуск
1. Открыть проект в Android Studio.
2. Собрать: `./gradlew assembleRelease`.
3. Установить APK на устройство Android 8.0+.
