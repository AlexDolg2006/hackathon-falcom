# Питомец Финни — hackathon-falcom

Игровой сервис для формирования базовых финансовых навыков у детей 7–11 лет
(конкурсное задание Департамента финансов города Москвы, ТЗ — `docs/ТЗ_Питомец_Финни.pdf`).
Godot 4.7, сборка под Android. Виртуальный кот: покупка еды и средств для купания,
настроение, сытость и чистота, магазин (обязательное — еда, мыло, мочалка; желаемое — шапки, игрушки),
ежедневная мини-игра «лови монетки», купание кота, план бюджета в процентах на 5 игровых дней
(обязательное / желаемое / накопления с фиксированным бонусом), финансовые задания,
накопления на цель, история и раздел для взрослого.

Пояснительная записка и полная документация (архитектура, структуры данных, формулы, карта
образовательного контента, тест-кейсы, доступность, лицензии) — `docs/ПОЯСНИТЕЛЬНАЯ_ЗАПИСКА.docx`
(та же информация в `docs/ПОЯСНИТЕЛЬНАЯ_ЗАПИСКА.md`).

## Стек
- Godot Engine 4.7 (GDScript), рендер Mobile, базовое окно 1080×1920, `canvas_items`, `expand`.
- Прогресс: JSON-файл `user://save_game.json`.
- Учебный и игровой контент — в `res://data/*.json` (магазин, задания, цели, справочник, п. 2.5.14 ТЗ).
- Питомец рисуется кодом (`PetCanvas.gd`, `_draw()`); внешних изображений, звуков и библиотек нет.

## Быстрый запуск (редактор)
1. Установить Godot 4.7 (stable).
2. Открыть папку проекта (`project.godot`).
3. Нажать Play (F5) — запустится `main_dashboard.tscn`.

## Сборка APK

### Требования к окружению
- Godot 4.7.2 и шаблоны экспорта той же версии;
- OpenJDK 17;
- Android SDK: platform-tools, build-tools 35.0.1, platforms;android-35, cmdline-tools (latest),
  CMake 3.10.2.4988404, NDK 28.1.13356709 (те же версии использует CI);
- пути к SDK и JDK в Godot: Editor → Editor Settings → Export → Android.

### Debug APK
`godot --headless --export-debug "Android" build/game.apk` или через редактор
(Project → Export → Android). CI `android-build.yml` собирает debug APK и публикует артефакт.

### Релизный подписанный APK (п. 3.3 ТЗ)
1. Создать ключ **вне репозитория**:
   `keytool -genkeypair -v -keystore ~/finni-release.keystore -alias finni -keyalg RSA -keysize 2048 -validity 10000`
2. Задать переменные окружения (значения в репозиторий не попадают):
   ```
   export GODOT_ANDROID_KEYSTORE_RELEASE_PATH=~/finni-release.keystore
   export GODOT_ANDROID_KEYSTORE_RELEASE_USER=finni
   export GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=<пароль>
   ```
3. Собрать: `godot --headless --export-release "Android" build/finni-release.apk`
4. Проверить: `apksigner verify --verbose build/finni-release.apk` и
   `aapt dump permissions build/finni-release.apk` (список разрешений должен быть пустым).

Через CI: в Settings → Secrets → Actions задать `ANDROID_KEYSTORE_BASE64` (`base64 -w0` от keystore),
`ANDROID_KEY_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`, затем создать тег: `git tag v1.0.0 && git push origin v1.0.0`.
APK появится во вкладке Releases.

## Демонстрационный режим и тестовый профиль
«Ещё ▾ → Раздел для взрослого» (решить пример) → кнопка сброса профиля к тестовому состоянию.
Профиль возвращается к исходному: 60 монет, стадия 0, пустая история. Приложение после сброса
лучше перезапустить: онбординг откроется при следующем запуске.

Ожидание реального времени не нужно: игровой день заканчивается кнопкой
«Завершить текущий день» (вкладка «Бюджет»), пятый день закрывает период.
Все задания открыты сразу. Пошаговая проверка — в документации, раздел «Тест-кейсы» (Приложение А ТЗ).

## Формулы и правила экономики
Константы находятся в начале `GameData.gd`.

- **Старт:** 60 монет в кошельке.
- **Бонус за вход:** +10 монет (`LOGIN_BONUS`), один раз за игровой день.
- **Доход за день:** +25 монет (`DAILY_INCOME`) автоматически при каждом нажатии «Завершить текущий день».
- **Мини-игра:** 20 секунд, 1 пойманная монета = +1 монета, одна попытка за игровой день.
- **Задание:** +10 монет за первое выполнение (повторное прохождение награды не даёт).
- **План бюджета в процентах:** обязательное + желаемое + накопления = 100%, обязательное больше 0
  (по умолчанию 50/30/20). При подтверждении весь кошелёк делится: `обязательное = floor(сумма × %)`,
  `желаемое = floor(сумма × %)`, накопления получают остаток. Накопления сразу увеличивают «накопления».
- **Доход внутри периода** (бонус, день, игра, задания) делится по тем же процентам между тремя
  направлениями, план (`plan_*`) растёт на те же суммы. Вне периода доход попадает в кошелёк.
- **Покупки** списываются из бюджета своей категории; при нехватке покупка блокируется и объясняется, сколько не хватает.
- **Игровой период = 5 игровых дней.** Каждый день: сытость −18; настроение −6 (ещё −8, если сытость < 30);
  чистота −10 (ещё −5, если сытость < 30). Значения ограничены 0…100. Купание повышает чистоту и немного настроение.
- **Завершение периода:** бонус `savings += round(savings × 0.05)`; остатки «обязательного» и «желаемого»
  возвращаются в кошелёк; следующий день не начнётся, пока не подтверждён новый план.
- **Срок цели:** `ceil((стоимость − накопления) / средний_взнос)`; средний взнос — среднее
  `plan_savings` по завершённым периодам (до первого — текущий план).
- **Рост питомца:** период «удачный», если на его конец сытость ≥ 40, настроение ≥ 50 и потрачено
  на обязательное больше 0; тогда +1 очко. 2 очка → «Подросший кот», 4 очка → «Взрослый кот-мудрец».
  Дебафов нет: питомец не болеет и не «умирает», только грустная мордочка (настроение < 35).

## Известные ограничения и план развития
- Питомец нарисован кодом; при желании заменяется спрайтами через `PetCanvas.gd`.
- Нет облака и аккаунтов; данные только на устройстве.
- Раздел для взрослого без веб-кабинета (вне минимума, п. 2.7).
- Автоматических тестов нет; логика в `GameData.gd` проверяется по тест-кейсам из записки. План: GUT/GdUnit4.
- Размеры интерфейса заданы в пикселях окна 1080×1920; на телефоне шириной 360 dp 1 px ≈ 1/3 dp,
  поэтому кнопки 44–48 px и шрифт 16 px меньше рекомендованных 48 dp и 16 sp. Масштаб интерфейса
  (`ui_scale`) есть в `GameData.gd`, но не сохраняется между запусками. Требуется проверка на устройстве.
- Звуков нет; отдельного переключателя анимаций нет.
- «Завершить текущий день» доступна ребёнку и даёт +25 монет за день; для релиза день стоит привязать к реальному времени.
- Награда за задание не читается из JSON (всегда 10), за любой выбранный ответ задание засчитывается.
- Запланировано: активное задание на главном экране, история покупок, возврат к подсказке,
  пояснения ко всем изменениям баланса, учёт плана и регулярности накоплений в росте питомца.

## Разрешения Android и данные
`export_presets.cfg` не включает ни одного разрешения (включая INTERNET), камеру, микрофон, геолокацию,
контакты, Bluetooth. Проверка собранного APK: `aapt dump permissions`. Все данные хранятся на устройстве
в `save_game.json`: имя питомца, внешний вид, баланс, накопления, история периодов, покупки, задания, чистота.
Персональные данные ребёнка и родителя не запрашиваются.

## Сброс и удаление данных
Взрослый сбрасывает или удаляет профиль в «Ещё ▾ → Раздел для взрослого»; действия требуют подтверждения.
`save_game.json` перезаписывается пустым профилем. Полностью данные исчезают при удалении приложения
или очистке его данных в настройках Android.
